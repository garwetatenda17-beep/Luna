# LUNA — one-file store builder (Zimbabwe)

`index.html` is the whole app. Open it in a browser, or deploy this folder to Vercel
(`vercel.json` makes `/shop/<shop-name>` links open the store).

- Product photos load live from images.unsplash.com.
- Data (shops, products, orders, wallet) is saved in the seller's browser.
- Store links carry the shop's products, so customers on any phone see the real store.
  Their orders reach the seller through a prefilled WhatsApp message.
- EcoCash is manual: the customer sends money with *151# and types the SMS code; the seller confirms it.
